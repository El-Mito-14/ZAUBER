# Zauber – Zauberwürfel-App

Web-App (PWA) für Android mit zwei Funktionen:

1. 3D-Zauberwürfel, der per Wischgesten gedreht werden kann (mischen, rückgängig, automatisch lösen).
2. Muster eines echten Würfels eintragen und eine Schritt-für-Schritt-Lösung (Schicht-für-Schicht-Methode) mit Animation erhalten.

Keine externen Bibliotheken, funktioniert nach dem ersten Laden auch offline.
